# SnapShelf · 截图暂存

面向学习和作业的 Mac 原生多截图暂存工具：连续截图、备注排序、滚动长截图、多图拼接，并可按顺序粘贴到 Chrome 文档中。

[直接下载最新版 macOS 安装包](https://github.com/xliu21722-sys/SnapShelf/releases/latest/download/SnapShelf-v0.1.0-macOS-arm64.zip) · [查看全部 Releases](https://github.com/xliu21722-sys/SnapShelf/releases)

## 下载与安装

需要 **macOS 14 或更新版本**，当前发布包支持 **Apple Silicon（M1/M2/M3/M4 等）**。

1. 在仓库右侧打开 **Releases**，进入最新版并下载 `SnapShelf-v0.1.0-macOS-arm64.zip`。
2. 解压后将“截图暂存.app”拖入“应用程序”文件夹。
3. 首次打开时，在 Finder 中右键应用并选择“打开”，然后确认打开。
4. 如果 macOS 仍提示无法验证开发者，在终端运行：

   ```sh
   xattr -dr com.apple.quarantine /Applications/截图暂存.app
   open /Applications/截图暂存.app
   ```

当前安装包使用本地临时签名，尚未经过 Apple 公证。请只从本仓库的 Release 下载，并核对 Release 页面提供的 SHA-256。后续有 Developer ID 后可换成正常签名和公证流程。

首次截图时，按界面提示在“系统设置 → 隐私与安全性 → 屏幕录制”中允许“截图暂存”。自动粘贴另需开启“辅助功能”。所有截图与备注只保存在本机。

## 功能

- `⌥ Option + S` 框选截图，自动加入暂存栏；系统鼠标指针不会进入图片。
- `⌥ Option + L` 框选区域后手动滚动，自动识别重叠内容并拼成长图。
- 为每张截图添加备注、拖动排序、删除及撤销删除，重启后恢复。
- 将所有截图与备注合成为一张 PNG，支持预览、复制和保存。
- 按图片与备注顺序自动粘贴到 Chrome 的可编辑文档；该功能仍需在不同网站中继续验证。

## 从源码构建

```sh
bash scripts/build-app.sh
open dist/截图暂存.app
```

构建需要 Apple Command Line Tools。脚本会生成并临时签名 `dist/截图暂存.app`。重新构建后 macOS 可能要求重新授权，建议固定应用路径后再授权。

关闭暂存窗口不会退出应用，可点击菜单栏的叠放图片图标重新打开；右键菜单提供退出。

## 操作

- **⌥ Option + S**：框选截图，松开鼠标后自动暂存，Esc 取消。截完仍留在原页面，可以继续截图。
- **⌥ Option + L**：框选滚动区域，避开固定标题栏和侧栏；慢慢向下滚动，短暂停顿后自动拼接。点击“完成”保存为一张截图，Esc 丢弃本次滚动捕获。
- **整理**：直接输入备注，拖动或用上下按钮调整顺序；删除后可撤销最近一次删除。
- **拼成长图**：将列表内所有图片及备注按顺序排版，预览后复制或保存 PNG。默认最大宽度 1600 px，可在设置中改成 1200/800 px；不放大小图。
- **粘贴到 Chrome**：先在可编辑文档正文点击插入位置，再点击工具的粘贴按钮。倒计时后按顺序发送图片和文字，Esc 停止。切换应用、窗口或输入焦点、改变剪贴板都会停止后续输入。原有剪贴板会被本次图片/备注替换。

快捷键可在设置中修改为 Option + 其他字母；操作系统报告注册失败时显示冲突提示。某些应用内部快捷键无法被系统注册机制检测，发生冲突时手动换一个字母。

## 滚动截图边界

工具只追加能够可靠匹配的新增内容，重复帧不追加。请每次滚动少于半屏并短暂停顿，保持原页面、窗口大小和缩放。匹配失败时暂停：向上回到预览末尾附近，保留至少半屏重叠，然后点击继续。反向滚动、动态内容、重复纹理、固定标题栏以及缩放可能导致暂停。页面本身绘制的鼠标图案和悬浮提示仍属于网页内容；系统鼠标指针和点击圆圈明确不捕获。

长图上限为 3200 万像素，单边不超过 32760 像素。达到上限后允许保存已有部分，不会丢弃已暂存图片。缩小导出宽度可降低合成图尺寸。没有 OCR、云同步或账号系统。

## 数据与恢复

本机数据位于 `~/Library/Application Support/SnapShelf/`：PNG 原图和 `library.json`。备注、顺序与最近一次可撤销删除均持久化。写入采用原子替换；损坏或未知版本的暂存记录不会被自动覆盖。可在应用退出后备份整个文件夹。每次新删除会清理上一次已删除且未恢复的图片。

## 验证

```sh
swift run SnapCoreChecks
```

检查程序无需完整 Xcode 或第三方依赖，兼容本机 Command Line Tools。自动化检查覆盖暂存恢复、备注和排序、删除撤销、损坏数据保护、精确滚动位移、重复帧、反向/过快滚动、模糊重叠拒绝、逐像素拼接、PNG 分辨率及导出尺寸限制。

`Tests/Fixtures/scroll-test.html` 提供带行号的滚动页面和本地可编辑粘贴区域。浏览器端与屏幕权限相关的人工验证步骤见 `VALIDATION.md`。

需要独立验证界面时，运行 `swift run SnapCoreChecks --ui-fixture` 生成测试暂存库，再使用 `open dist/截图暂存.app --args --data-directory <输出的测试目录>` 启动（先退出已运行的实例）。不带该参数时始终使用正式本机目录。

**飞书适配状态：待真实文档验证。** 原生输入模拟不提供飞书上传完成/云端保存确认；“已发送”仅表示已发出操作。需在用户指定的飞书测试文档中验证图片、备注、顺序及慢速网络。严格焦点检查在某些编辑器更新焦点时可能暂停，应用会保留暂存内容，不自动重发，避免重复插入。
